# 52pj 功能设计

> 吾爱破解（52pojie.cn）命令行阅读器。本文讲**能做什么、怎么用**；
> 内部实现见 [架构设计.md](架构设计.md)。

## 1. 定位

一个**只读**的命令行论坛阅读器——列板块、列帖子、读楼层、搜索。
唯一的写操作是每日签到（`sign`），用于领取论坛币。

除 `sign` 外**没有**发帖、回帖、点赞等任何写入能力，代码里也不存在相关实现。

## 2. 安装

```bash
git clone https://github.com/itingyu/52pojie.git
cd 52pj
pip install .
52pj setup          # 一次装齐：curl_cffi / beautifulsoup4 / playwright
```

三个都是硬依赖，缺了直接退出：`curl_cffi`（Chrome TLS 指纹）、
`beautifulsoup4`（解析）、`playwright`（驱动本机浏览器）。

国内网络 pip 连不上默认源时换镜像：

```bash
pip install . -i https://pypi.tuna.tsinghua.edu.cn/simple
```

Windows 用户也可直接用 `52pj.bat`（薄壳，内部就是 `python pojie.py %*`）。

## 3. 快速上手

```bash
52pj forums                    # 列出版块（30 个）
52pj select 病毒分析            # 选定板块（之后命令都作用于它）
52pj threads                   # 列该板块帖子
52pj select 2137132           # 选定帖子
52pj thread                    # 读正文和楼层
52pj status                    # 看当前选中了什么
```

**上下文机制**：选一次，之后命令默认作用于它，不用反复传参数。
规则是**显式参数优先**；执行成功的结果会自动记为当前选择；
`--keep` 可以临时看一眼而不改动选择。

## 4. 命令

### 4.1 板块与帖子

| 命令 | 说明 |
|---|---|
| `forums` | 列出所有版块（序号 + FID + 名称） |
| `forums --grep 病毒` | 按名称过滤版块 |
| `threads` | 列出当前选中板块的帖子 |
| `threads --fid 32` | 指定板块（会更新选择） |
| `threads -f 水漫金山` | **板块名可以直接写**，不用记 fid |
| `threads -f 32 --grep 求助` | 列表页本地关键字过滤 |
| `threads -f 32 --no-pin` | 不显示置顶帖 |
| `threads -f 32 --pin-only` | 只看置顶帖 |
| `threads -f 32 --page 2` | 翻页 |
| `latest` | 全站新帖导读 |
| `latest --grep 勒索` | 新帖里过滤 |

### 4.2 读帖子

| 命令 | 说明 |
|---|---|
| `thread 2137132` | 看正文和各楼回复 |
| `thread https://www.52pojie.cn/thread-2137132-1-1.html` | **直接粘网址** |
| `thread 2137132 --page 2` | 看第 2 页楼层 |
| `thread 2137132 --pager` | **交互式阅读**（见下） |
| `thread 2137132 --next` / `--prev` | 翻页（会记住页码） |
| `thread 2137132 --floor 88` | 跳到第 88 楼（自动定位所在页） |
| `thread 2137132 --all` | 一次抓全部分页（脚本/导出用） |
| `thread 2137132 --op` | **只看楼主**（服务端 `authorid` 过滤，等同页面上的「只看该作者」） |
| `thread 2137132 --author 某人` | 只看指定昵称 |

### 4.3 交互式阅读器

```bash
52pj thread 2137132 --pager
```

| 按键 | 作用 |
|---|---|
| ↑↓ / j k | 上一行 / 下一行 |
| PgUp PgDn / 空格 | 上一屏 / 下一屏 |
| ←→ | 上一页 / 下一页 |
| n p | 同上（字母键） |
| g G | 跳到最前 / 最后 |
| q | 退出 |

读到某页底部会自动加载下一页。非终端环境下自动退化成一次性全部打印。

### 4.4 搜索

```bash
52pj search 银狐
52pj search 银狐 --engine bing     # 360 优先，Bing 兜底
```

**注意**：站点站内搜索（`search.php`）一律 302 到 Bing，而 Bing 对本站几乎无索引，
所以 `search` 走 360 / Bing 外链解析。**搜不到就翻版块列表**，或用
`threads --grep` / `latest --grep` 本地过滤。

### 4.5 登录

```bash
52pj auth                        # 打开本机浏览器人工登录，工具自动收回 cookie
52pj login -u 账号 -p 密码        # 账号密码登录（站点要 Turnstile 时会失败）
52pj login --cookie "k=v; k2=v2" # 直接导入整行浏览器 Cookie
52pj whoami                      # 查登录状态
52pj logout                      # 清除本地登录态
```

`auth` 会打开系统默认浏览器，用**同一个 profile**（`~/.52pj/browser-profile`），
所以登录一次，`auth` 与 `-b` 都能复用。

站点登录要过 Cloudflare Turnstile，纯脚本过不了，所以设计成
「打开浏览器由你手动登录、工具回收 cookie」。也支持 `login --cookie "..."` 直接导入。

**游客态的能力边界**：非私密帖的第 1 页可读；第 2 页起标题与楼层都缺失
（页面返回的是登录提示页）；私密版块直接被拦。登录后这些都正常。

### 4.6 签到（唯一的写操作）

```bash
52pj sign            # 每日签到，领取论坛币
52pj sign --webview  # 借 App 的 WebView 签到（App 已登录时）
```

签到入口是积分页上的「领取今日签到奖励」，由服务端按是否已签到决定是否渲染：

- **未签到** → 页面有 `mod=task&do=apply` 链接，访问即完成签到；
- **已签到** → 页面没有该链接，直接告知「今天已经签过到了」。

工具会访问签到链接后再回积分页复查，确认入口已消失才算成功；
若仍在则报「签到未生效」（站点可能要求安全提问等额外验证，需手动签到）。

未登录会直接报错。

| 命令 | 说明 |

## 5. 浏览器传输层（`-b`）

`-b` 让请求借道浏览器发出，用浏览器自带的登录态：

```bash
52pj -b threads -f 10
```

三种后端：

| 写法 | 后端 | 登录态来自 | 可用环境 |
|---|---|---|---|
| `52pj -b forums` | 自动选 | — | 通用 |
| `52pj --webview forums`（`-W`） | Minis App 内的 WebView | App 的 cookie（HttpOnly） | App / 沙箱内 |
| `52pj --local forums`（`-L`） | 本机默认浏览器（Playwright 驱动） | 本机浏览器 profile | 桌面宿主 |

自动选规则：有 `minis-browser-use` 通道就用 App 的 WebView，否则用本机浏览器。
强制指定后若当前环境不具备该条件，会**直接报错说明原因**，不会静默换用别的后端。

不加 `-b` 就是默认的本地直连（curl 指纹，只带本地 cookie 库里的 cookie）。

## 6. 全局开关

| 开关 | 作用 |
|---|---|
| `-b` / `--browser` | 借道浏览器发请求（自动选后端） |
| `-W` / `--webview` | 强制用 Minis App 内已登录的 WebView |
| `-L` / `--local` | 强制用本机默认浏览器（Playwright 驱动） |
| `--headed` | 浏览器后端显示窗口（默认无头；`auth` / `login -u/-p` 恒定有头） |
| `--home DIR` | 换配置目录（默认 `~/.52pj`） |
| `--delay 1.0` | 请求间隔基准值，实际是基准 ± 抖动（0.7–1.3 秒） |
| `--delay-min` / `--delay-max` | 单独指定间隔上下界 |
| `--cookie-file FILE` | 换 cookie 库文件 |
| `--json` | 输出 JSON，便于脚本处理 |
| `--color` / `--no-color` | 开关彩色输出 |
| `--width N` | 指定输出宽度（默认取终端宽度） |

## 7. JSON 输出

```bash
52pj --json forums             # [{"fid": 2, "name": "原创发布区"}, ...]
52pj --json threads -f 24
52pj --json thread 2137132     # {"tid":..., "title":..., "posts":[{pid,author,floor,time,content}]}
52pj --json status             # {"board":..., "thread":..., "logged_in":true, "user":...}
```

## 8. 排版与编码

**排版**：表格列宽受终端宽度约束，超长标题会截断加 `…`；窄终端（50 列）下表格会收窄但不会折行。

**编码**：输出编码自动适配，不用手工设置——

- 重定向到文件/管道 → 纯 UTF-8，**不带 BOM**；
- 交互终端 → 自动把控制台切到 65001（UTF-8），切不动退回系统编码；
- `52PJ_ENCODING=utf-8|native|gbk` 可强制。

站点是 GBK 编码，内容已正确解码，直接读输出即可。

## 9. 数据位置

| 路径 | 内容 |
|---|---|
| `~/.52pj/52pj.db` | SQLite：cookie、列表缓存（cookie 是明文） |
| `~/.52pj/state.json` | 当前选中的板块/帖子 |
| `~/.52pj/browser-profile/` | 本机浏览器 profile（登录态） |

## 10. 环境变量

| 变量 | 作用 |
|---|---|
| `52PJ_ENCODING` | 强制输出编码：`utf-8` / `native` / `gbk`（默认自动适配） |
| `NO_COLOR` | 存在即关闭彩色输出 |
| `POJIE_COLOR` | 设为 `1` / `true` / `yes` / `on` 开启彩色输出 |
| `POJIE_IMPERSONATE` | curl_cffi impersonate profile，默认 `chrome` |
| `POJIE_52_ACCOUNT` | 账号（`login -u` 省略时读取） |
| `POJIE_52_PASSWD` | 密码（`login -p` 省略时读取） |

账号密码读取顺序：进程环境 → Windows 用户级注册表 → 交互输入。

## 11. 已知限制

- **除 `sign` 外全部只读**：不能发帖、回帖、点赞。
- **游客态**：私密版块被拦；非私密帖的第 1 页可读，第 2 页起标题与楼层缺失。
- **搜索依赖第三方引擎**，站内索引不全，搜不到就翻版块列表。
- **登录是 Cloudflare Turnstile**：无法纯脚本过验证，设计成人工登录 + 回收 cookie。
- **楼号是推算的**：Discuz 楼号由 JS 渲染，HTML 里没有，工具按 DOM 顺序推算
  （每页 10 楼）。用「只看该作者」筛选时站点会重新编号，工具保留站点标记不猜数字。
- **`--local` 需要桌面环境**：Playwright 驱动的是本机浏览器，沙箱/App 内不可用。
